# Town Of Host-Temp

## このMODについて

**Town Of Host-Temp** は、Among Us向けの非公式MODです。

本MODは **Town Of Host** をフォーク元として開発されており、会議処理などの一部について **TownOfHost-K** を参考にしています。

Among Us公式やInnerslothが本MODの開発・運営に関与しているものではありません。

本MODに関する問題・質問等について、Among Us公式やInnerslothへ問い合わせないでください。

## 特徴

本MODは、ホストのクライアントに導入することで動作します。

他のプレイヤーが本MODを導入していなくても、基本的にホストの部屋へ参加してプレイすることができます。

また、カスタムサーバーを利用するタイプのMODとは異なり、基本的にサーバーの追加設定などを必要としません。

### 注意

ホストが途中で退出するなどしてホストが変更された場合、MODによる特殊な処理が正常に動作しなくなる可能性があります。

また、環境や他MODとの組み合わせによって正常に動作しない場合があります。

---

## MODを導入しているクライアントについて

ホスト以外のプレイヤーが本MODを導入した状態でプレイした場合、環境によって以下のような変更が発生する場合があります。

* 特殊役職独自の開始画面
* 特殊役職の勝利画面
* MODによる設定項目
* その他、MODクライアント向けの機能

# テンプレート

定型文を登録し、ゲーム内から呼び出せる機能です。

`/template <タグ>` または `/t <タグ>` で呼び出すことができます。

テンプレートを設定するには、Among Us.exeと同じフォルダにある

```text
./TOH_DATA/template.txt
```

を編集します。

基本的に、

```text
タグ:内容
```

という形式で記述します。

### 改行

文章中に `\n` を記述すると改行できます。

例:

```text
test:これは\nテストです
```

---

## 特殊タグ

ゲーム内の特定のタイミングで、自動的にテンプレートを送信できる特殊タグがあります。

例:

```text
welcome:この部屋はTown Of Host-Tempを使用しています。
```

| タグ               | シーン      | 対象        |
| ---------------- | -------- | --------- |
| `welcome`        | プレイヤー入室時 | 入室したプレイヤー |
| `OnMeeting`      | 会議開始時    | 全員        |
| `OnFirstMeeting` | 初回会議開始時  | 全員        |

---

## 変数展開

文章中に `{{変数名}}` の形式で記述すると、テンプレート呼び出し時に変数の内容を展開できます。

例:

```text
roomcode:この部屋のルームコードは{{RoomCode}}です
```

| 変数名              | 内容               |
| ---------------- | ---------------- |
| `RoomCode`       | ルームコード           |
| `PlayerName`     | ホストのプレイヤー名       |
| `AmongUsVersion` | Among Us本体のバージョン |
| `ModVersion`     | MODのバージョン        |
| `MapName`        | 現在のマップ名          |

※利用できる変数はアップデートによって変更される場合があります。
